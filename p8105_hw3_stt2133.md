### Data Description

The `ny_noaa` dataset provides information on weather data in New York.
Each observation represents each day from 1981-01-01 to 2010-12-31,
resulting in 2595176 total observations. There are 7 variables in the
dataset, including the weather station ID (`id`), daily precipitation
(`prcp`), daily snowfall (`snow`), daily snow depth (`snwd`), and
maximum and minimum daily temperature (`tmax`, `tmin`). Among all
observation in the dataset, there is 0% and 0% missing data in regards
to weather station ID (`id`) and date (`date`) of observation,
respectively. However, there is more extensive missing data in regard to
the other weather-related values. Specifically, among all observations
in the `ny_noaa` dataset 5.62% of precipitation (`prcp`) data is
missing, 14.69% of snowfall (`snow`) data is missing, 22.8% of snow
depth (`snwd`) data is missing, 43.71% of maximum temperature (`tmax`)
data is missing, and 43.71% of minimum temperature (`tmin`) data is
missing.
